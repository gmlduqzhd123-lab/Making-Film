## 부분 구현·미구현 체크리스트

### v1.0의 선택 사항·추가 개선

- [ ] **PRD 8 방식 C:** 같은 origin 웹앱 직접 로딩 UI. 현재 A/B의 직접 업로드와 D의 메타데이터·링크만 사용합니다.
- [ ] **PRD 9 / 22:** 자동으로 장면별 효과음 종류·사용 시점을 추천하는 데이터. 현재는 사용자가 장면에 음원을 직접 연결합니다.
- [ ] **PRD 35:** 다크모드. MVP 선택 사항이므로 밝은 테마만 구현했습니다.
- [ ] **PRD 44:** 별도의 Problem 장면과 가변 장면 수를 만드는 스마트 구성. 현재는 PRD 10의 고정 9개 구조이며, 기능 1–3은 개별 장면, 기능 4–5는 가치 장면에 함께 반영합니다.
- [ ] **PRD 53:** 실제 화면 50%·상황 30%·타이포그래피 20%를 이미지 유형에 따라 자동 배분. 프롬프트에 권장 비율을 포함하지만 장면 생성은 업로드 화면을 우선 재사용합니다.
- [ ] **PRD 55:** 수업 준비 시간 절감의 별도 입력·강조. 확인되지 않은 절감 효과는 만들지 않습니다. 접근·활용 학년·시간·참여 정보는 입력값을 반영합니다.
- [ ] **PRD 60:** 실제 Pages 네트워크 조건에서 3초 로딩 목표 측정. 정적 파일 실행과 로컬 호스팅은 검증했으며 실제 배포 환경의 성능은 별도 확인이 필요합니다.
- [ ] **PRD 58:** 제안된 모든 파일명을 그대로 분리. 기능별 모듈은 구현했으며 작은 모듈은 합쳤습니다. 예를 들어 음악·애니메이션·타임라인 재생은 내보내기와 재사용하는 `player.js`에 있습니다. JSON은 file:// 호환 카탈로그에도 포함됩니다.
- [ ] Safari·Firefox·실제 iPad에서의 별도 기기 검증. 현재 Windows Chrome/Edge와 태블릿 크기의 브라우저 viewport에서 검증했습니다.
