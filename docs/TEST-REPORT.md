# v1.0 동작 검증 기록

v1.1 PRD 입력 기능과 추가 회귀 검증은 [PRD-TEST-REPORT.md](PRD-TEST-REPORT.md)에 있습니다. 아래는 v1.0의 원래 검증 기록입니다.

검증일: 2026-10-04 (Asia/Seoul).

## 결과

Windows Chrome와 Microsoft Edge에서 자동 브라우저 검사 **각 30개 시나리오**를 실행했습니다. 페이지 예외·콘솔 오류 **0건**, 외부 서비스 네트워크 요청 **0건**입니다.

파일을 직접 여는 `file://` 환경, 그리고 `/Making-Film/` 하위 경로에 변경 없이 파일만 제공하는 임시 정적 호스팅 환경을 검사했습니다. 실제 GitHub 저장소 업로드·Pages 활성화·배포 URL 검증은 이 결과에 포함되지 않습니다.

## 주요 검증

| 영역 | 검증 내용 |
|---|---|
| 시작 | 홈, 온보딩, 신규 프로젝트, 6개 샘플 |
| Wizard | 빈 입력 차단, 핵심 기능 최대 5개·순서 변경 |
| 자동 저장 | 입력창 포커스를 유지한 채 입력 후 1초 저장 |
| 이미지 | 실제 PNG 두 장 업로드, WebP 변환, 2400px → 1920px |
| 생성 | 정확한 30/45/60/90초, 9개 장면, 연속 시작·종료, 다섯 번째 기능 반영 |
| 플레이어 | 실제 시간 진행, 정지, ±10초, 처음, 음소거, 자막, 전체화면, 마지막 프레임 정지 |
| 편집 | 문구·내레이션·시간 변경, Preview·Timeline 반영 |
| Scene 관리 | 추가·삭제·복제, Ctrl+D·Delete, 드래그 정렬, 이미지 교체 |
| 이력 | Undo/Redo와 30회 이상 복구 |
| 스타일 | 8개 테마, 13개 화면 효과, 6개 문구 효과 렌더링 |
| 음악 | 로컬 PCM WAV의 BGM·Scene 효과음 업로드 및 재생 경로, JSON 포함 |
| 프롬프트 | Codex TXT 다운로드, Scene 프롬프트 탭, 이미지 없는 장면의 이미지 프롬프트 |
| 문서 출력 | SRT 시간 형식, 전체 내레이션 TXT, scenes.json |
| 원본 | 이미지·음악이 포함된 project.json 다운로드·복원 |
| 파일 입력 | 손상 JSON·외부 이미지 주소·지원하지 않는 구조의 거부 |
| HTML | 자체 포함 이미지, 독립 실행, 자동재생 시간 진행 |
| ZIP | 필수 파일, 상대 경로 이미지·음악, 압축 해제 후 파일 직접 재생 |
| Dashboard | 저장, 복제, JSON 다운로드, 삭제 후 새로고침 |
| 반응형 | 1440px PC, 1024px/768px 태블릿, 390px 모바일 가로 넘침 없음 |
| Pages 경로 | `/Making-Film/` 상대 경로, 해시 화면 이동, 새로고침 후 저장 프로젝트 열기 |
| 저장 오류 | 강제 QuotaExceededError 안내와 JSON 저장 대체 |
| 텍스트 처리 | HTML 내보내기에서 script 종료 문자열을 입력해도 코드로 실행되지 않음 |
| 오류 | 손상된 로컬 저장 항목이 Dashboard를 중단하지 않음 |

ZIP의 CRC32와 항목 목록은 Python 표준 `zipfile`로 추가 검사했습니다. JS 문법과 JSON 파일도 검사했습니다. 상세 기계 판정은 `verification-chrome.json`과 `verification-edge.json`에 포함됩니다.

## 수정한 문제

- 샘플 SVG의 잘못된 닫힘 태그로 예시 이미지가 표시되지 않던 문제.
- 재생 전 첫 장면 문구가 투명하게 남아 있던 문제.
- 입력창을 벗어날 때 화면 전체가 교체되어 다음 단계 클릭이 사라지던 문제. 입력과 Preview 갱신을 분리했습니다.
- Pages 하위 경로에서 새로고침 후 같은 `#editor` 경로를 다시 열지 못하던 문제.
- 삭제한 프로젝트가 현재 열린 프로젝트의 저장으로 다시 생길 수 있던 문제.
- 이미지가 있는 Minimal 테마의 어두운 글자 대비 문제.
- 편집 중 시간 정보가 화면 일부에 늦게 반영되던 문제.
- 연속 다운로드 안내가 화면을 과도하게 가리던 문제. 중복 안내를 제거하고 최대 3개로 제한했습니다.

## 해석 범위

검증은 HTML 영상 경험과 로컬 파일 출력의 기능을 확인합니다. MP4 생성, 음성 합성 품질, 실제 수업 효과, 실제 모바일 기기 성능을 검증한 결과가 아닙니다. 한국어 미리듣기는 사용 환경에 한국어 음성이 있을 때 제공하며, 자동재생 음원은 브라우저 정책의 영향을 받습니다.

GitHub Pages 공개 URL의 정상 동작은 원격 업로드와 Pages 활성화 후 확인해야 합니다.

## 다시 검사하기

Node와 Playwright가 있는 개발 환경에서 프로젝트 루트 기준으로 `node tests/e2e.cjs`를 실행합니다. Chrome은 기본 채널이며 Edge는 `YVM_BROWSER_CHANNEL=msedge`를 지정합니다. 앱 자체를 실행하는 데에는 Node나 Playwright가 필요하지 않습니다.
