# 5분 안에 첫 영상 만들기

1. `index.html`을 엽니다. 먼저 **땀방울 원정대 → 샘플 열기**로 미리보기를 확인할 수 있습니다.
2. **내 웹앱 영상 만들기**에서 웹앱 이름과 한 줄 소개를 입력합니다.
3. 가장 보여주고 싶은 기능 3개를 입력하고 스크린샷 5장 정도를 올립니다. 1장으로도 시작할 수 있습니다.
4. 기본 60초와 추천 스타일을 선택하고 **영상 구성 만들기**를 누릅니다.
5. 재생하며 어색한 문구를 오른쪽 카드에서 고칩니다. 내레이션이 긴 장면은 문장을 줄이거나 시간을 늘립니다.
6. **JSON 저장**으로 원본을 보관하고 **영상 내보내기**로 ZIP을 다운로드합니다.
7. ZIP을 풀고 그 안의 `index.html`을 엽니다. 자동재생하며 음악이 안 들리면 재생 버튼을 다시 누릅니다.

## 가장 자주 하는 편집

- **장면 순서:** 오른쪽 카드를 끌어다 놓거나, 선택한 뒤 ↑/↓를 누릅니다.
- **이미지 교체:** 장면의 화면 이미지 목록에서 선택합니다. 화면 자료 단계에서 새 이미지를 넣어도 됩니다.
- **자막 수정:** 내레이션 / 자막 입력란을 수정합니다. 내보내는 SRT도 같은 내용으로 바뀝니다.
- **전체 시간 조정:** 장면 길이를 수정합니다. 시작 시간은 자동으로 이어집니다.
- **실수 복구:** Ctrl+Z. 장면 구성 전체를 다시 만든 경우도 되돌릴 수 있습니다.
- **다른 기기에서 작업:** `project.json`을 옮겨 홈의 프로젝트 불러오기로 엽니다.
- **영상만 전달:** 단독 HTML은 한 파일에 이미지·음악을 담습니다. ZIP은 편집 원본·대본·자막까지 함께 전달합니다.

## 안내 메시지 이해하기

**JSON 저장 필요:** 브라우저 저장 용량이 부족하거나 저장이 차단된 상태입니다. 작업을 유지하려면 JSON을 다운로드합니다.

**내레이션이 길 수 있습니다:** 초당 3.5음절을 기준으로 한 예상치입니다. 실제 말하는 속도로 읽어 보고 수정합니다.

**샘플 예시 화면:** 샘플은 자체 제작한 예시 그림입니다. 실제 서비스를 소개하려면 직접 캡처한 화면으로 바꿉니다.

**한국어 음성이 없습니다:** 이 운영체제·브라우저에서 한국어 미리듣기를 사용할 수 없습니다. 대본과 SRT 다운로드는 계속 사용할 수 있습니다.

HTML 영상은 MP4가 아닙니다. 내레이션은 텍스트이며 음성 파일은 자동 생성되지 않습니다. 앱의 URL은 이동 링크로만 사용됩니다.
